أداة بحث محلية تعمل بدون إنترنت، مصممة لمسح كميات ضخمة من الملفات المتنوعة (`.txt`, `.csv`, `.sql`, `.json`, `.log` وغيرها) المخزّنة على هارد ديسك بطيء — بسرعة عالية.

## المميزات

- **محرك Ripgrep** — بحث سطري متعدد الخيوط (Threads) مكتوب بلغة Rust.
- **فهرس SQLite FTS5 (Trigram) دائم** — تبني الفهرس مرة واحدة، وكل بحث بعد ذلك يعتمد على قائمة مرشّحة صغيرة من الملفات بدل مسح القرص كله من جديد. استخدام Trigram يعني بحث حقيقي عن **جزء من النص** (إيميل جزئي، رقم تليفون، كلمة ناقصة) وليس فقط كلمات كاملة. الملفات الأكبر من 64 ميجا تُتابَع كبيانات وصفية فقط وتُمسح مباشرة دائمًا (فهرسة محتواها غير مجدية — ريبجريب نفسه يقرأ ملف بحجم عدة جيجا في ثوانٍ).
- **تراجع تلقائي آمن** — لو مفيش فهرس، أو كلمة البحث أقل من 3 حروف، أو وضع Regex، البحث يرجع تلقائيًا لمسح مباشر كامل. النتائج أبدًا لا تكون ناقصة بدون تنبيه.
- **نتائج متدفقة لحظيًا (Streaming)** — النتائج تظهر وهي تُكتشف، بدون انتظار انتهاء المسح.
- **أوضاع بحث OR / AND / Regex**، واجهة ثنائية اللغة (عربي/إنجليزي)، تصدير JSON، نسخ سريع.

## المتطلبات

1. Python 3.10 أو أحدث
2. [Ripgrep](https://github.com/BurntSushi/ripgrep) (`rg`) مضاف إلى PATH — `scoop install ripgrep` أو `choco install ripgrep`
3. `pip install fastapi uvicorn`

## تشغيل البرنامج

```bash
python server.py
```
أو اضغط دبل كليك على `start_deadline.bat`. يفتح تلقائيًا على `http://127.0.0.1:8000`.

## نصائح الاستخدام

- اكتب أكثر من كلمة مفصولة بـ `|` أو فاصلة: `01012345678 | admin@target.com | John Doe`
- غيّر حقل **المسار** لأي فولدر، سواء على القرص المحلي أو هارد خارجي.
- اضغط **بناء الفهرس (Index)** مرة واحدة لكل مجموعة بيانات لتحصل على بحث أسرع بشكل كبير في المرات التالية (أول بناء يقرأ كل الملفات مرة واحدة كأنه مسح كامل، ويستحق ذلك لو هتبحث في البيانات أكتر من مرة). التحديثات بعد ذلك تتم بشكل تراكمي — فقط الملفات التي تغيّرت تُعاد فهرستها.
- الفهرس موجود في مجلد الهوم (Home) بتاعك، مش داخل الفولدر اللي بتبحث فيه، عشان ميتعارضش مع المسح على نفس القرص ومايشغلش مساحة منه.
- يحتاج الفهرس كلمات بحث 3 حروف فأكثر؛ الكلمات الأقصر واستعلامات Regex تعمل مسح كامل دائمًا.

## تنبيه

البرنامج مصمم للاستخدام في أبحاث الأمن السيبراني المُصرَّح بها، اختبار الاختراق، وتحليل بيانات OSINT. المسؤولية الكاملة عن الاستخدام تقع على المستخدم.
