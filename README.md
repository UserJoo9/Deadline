---

## 🌟 المميزات الرئيسية (Key Features)

- ⚡ **محرك فائق السرعة يعتمد على Ripgrep (Rust Core)**: فحص مئات الجيجابايتات من الملفات النصية، ملفات الـ SQL Dumps، والـ CSVs في ثوانٍ معدودة.
- 📡 **بث النتائج الحي (Real-time SSE Streaming)**: عرض النتائج فور العثور عليها سطر بسطر بدون انتظار انتهاء الفحص بالكامل.
- 💻 **واجهة Terminal / Dark Cyberpunk احترافية**: تصميم مظلم مستوحى من أدوات الاختراق المتقدمة (Matrix/Hacker Aesthetic) مع تأثيرات Scanlines ونصوص Monospace.
- 🌐 **دعم كامل للغتين (العربية / English)**: تبديل فوري بضغطة زر واحدة.
- ⚙️ **حفظ الإعدادات تلقائياً (Auto-persistence)**: حفظ مسار البحث واللغة المفضلة في المتصفح تلقائياً عبر `localStorage`.
- 📁 **تخصيص مجلد البحث ديناميكياً**: إمكانية تغيير مسار البحث لأي مجلد خارجي أو فرعي مباشرة من الواجهة.
- 📋 **نسخ فردي وجماعي متطور (Copy / Copy All)**:
  - نسخ أي سطر مطابق بضغطة زر مع علامة تأكيد `✓` وإشعار نيون طافي (Toast Notification).
  - زر **"نسخ الكل (Copy All)"** في أعلى الجدول لنسخ كافة النتائج المستخرجة دفعة واحدة.
- 💾 **تصدير النتائج (JSON Export)**: حفظ نتائج الاستعلام كملف JSON مرتب ومنظم للتحليل لاحقاً.
- 🔍 **أوضاع بحث متعددة**:
  - **OR (مطابقة أي قيمة)**: للبحث عن عدة أرقام أو إيميلات مفصولة بـ `|` أو فاصلة.
  - **AND (جميع الكلمات معاً)**: للبحث المتقاطع والفلترة الدقيقة داخل السطر الواحد.
  - **Regex (النمط المتقدم)**: لدعم التعابير القياسية المعقدة.

## 🚀 متطلبات التشغيل (Prerequisites)

1. **Python 3.10 أو أحدث**.
2. **Ripgrep (`rg`)**: متوفر عبر `scoop install ripgrep` أو `choco install ripgrep` أو عبر وضعه في الـ PATH.
3. تثبيت المكتبات المطلوبة:

```bash
pip install fastapi uvicorn
```

## 🛠️ طريقة التشغيل (How to Run)

### الطريقة الأولى (الأساسية):
اضغط مرتين على ملف التشغيل:
```cmd
start_deadline.bat
```

### الطريقة الثانية (عبر السطر البرمجي):
```bash
python server.py
```

بعد التشغيل، سيفتح المتصفح تلقائياً على الرابط:
👉 **`http://127.0.0.1:8000`**

## 💡 نصائح الاستخدام (Pro Tips)

- **البحث المتعدد**: يمكنك إدخال عدة أرقام أو كلمات بحث دفعة واحدة مثل:
  ```text
  01012345678 | admin@target.com | John Doe
  ```
- **تحديد مسار مخصص**: اكتب مسار أي هارد خارجي أو مجلد تريده في خانة `المسار` بالأعلى وسيقوم البرنامج بحفظه واستخدامه فوراً.
- **إلغاء البحث في أي وقت**: يمكنك الضغط على زر `إيقاف (Stop)` الأحمر لإيقاف الفحص الجاري فوراً دون إغلاق المتصفح أو السيرفر.
